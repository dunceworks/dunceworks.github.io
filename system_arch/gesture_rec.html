Gesture Recognition Algorithm

  The software inference pipeline relies on MediaPipe Hands to process the downscaled frames, detecting the user's hand and extracting 21 specific 3D landmark keypoints (x, y, z). Once extracted, these spatial coordinates are fed into a Multi-Layer Perceptron (MLP) gesture recognizer. The MLP interprets the landmark patterns to classify the user's hand position and generates a corresponding control command.

  The SoC queries the VDMA IP for the latest downscaled frame and then copies the frame from the frame buffer for processing. The gesture recognizer then processes the frame and outputs a gesture classification. This classification is transmitted via UDP over ethernet to the Rubik Pi 3, which uses the data to update the SBS video stream and control the rover.
