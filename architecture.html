Overall Architecture

  The overall architecture of FAST-AR utilizes both a dedicated hardware/PL accelerator along with multiple software/PS components. The hardware accelerator substantially reduces CPU and memory overhead for the gesture recognizer, while the software component of the AUP-ZU3 SoC manages the actual detection and classification.
 There are additionally several other software components off-board of the AUP-ZU3 that manage Side-by-Side (SBS) stereo vision and remote control of a rover using the recognized gestures.

Hardware-Accelerated Architecture

Gesture Acceleration

A MIPI CSI camera (PCAM5) clocked at 200MHz feeds into a demosaic module (Vivado IP) converting the raw bayer data into standard RGB. Here, the data stream splits. One stream is grayscaled, while the other stream remains RGB. The RGB stream is then fed into the downscaler (detailed below) while the grayscale stream is sent to the mDP output to aid framing the camera feed for the user.

Software Architecture

Gesture Recognition

To provide instructions to the rover, the ARM cores (SoC) on the AUP-ZU3 run a gesture recognition pipeline. We run MediaPipe Hands on a downscaled image to detect the user's hand and extract the gesture. This gesture is then transmitted to the rover and used as commands to control the rover's movement.

Side By Side (SBS) Stereo Vision

For user vision and to provide updates on the gesture recognizer and rover status, a SBS stereo vision stream is used. One Rubik Pi captures a full HD (1080p) frame at 60FPS from the rover, intakes data from the AUP-ZU3 via UDP over ethernet, and uses that data to display the rover and gesture recognizer status.

Remote Control (Demo)

Our demo showcases a potential use of gesture acceleration in the FAST-AR system to control a rover. The rover receives commands from the AUP-ZU3 and transmits video back to the user via a WiFi connection. The user can then use the gesture recognizer to control the rover's movement and receive real-time feedback on the rover's status and surroundings through the SBS stereo vision stream.
